# Tackroom

개인용 Claude Code 플러그인 저장소다.

## kowrite

한국어 문서·주석·커밋의 규칙을 지키게 하는 플러그인이다.
세션을 시작할 때 규칙 네 줄을 지시하고, 어기면 훅이 알리거나 막는다.
규칙을 지키면 훅은 아무것도 출력하지 않는다.
모델은 호출하지 않는다.

### 규칙

**1. 문장은 짧게 쓰고, 한 문장이 끝나면 줄을 바꾼다.**

- 편집 직후에 알린다.
- 커밋 직전과 응답 종료 전에 막는다.
- Markdown은 이어진 줄을 한 문단으로 합친다. 그래서 문단의 줄은 문장으로 끝나야 한다.
- 주석과 커밋 본문은 명사형 문체가 흔하다. 그래서 조사, 연결 어미, 쉼표처럼 문장이 이어질 수밖에 없는 끝만 잡는다.

**2. 커밋 메시지에 도구·모델 표기와 세션 링크를 넣지 않는다.**

- 커밋 직전에 막는다.
- 사람 공동 작성자는 막지 않는다.

**3. 문서의 수치는 코드 상수와 묶는다.**

- 값 앞에 `<!-- const: 경로:상수 -->`를 붙인다.
- 값이 상수와 다르면 편집 직후에 알리고, 종료 전에 막는다.

**4. 코드를 설명하는 문서는 대상을 밝힌다.**

- 문서에 `<!-- tracks: 경로 -->`를 적는다.
- 대상 코드만 바뀌고 문서가 그대로면 종료 전에 막는다.

### 검사 범위

- 종료 전 검사는 세션을 시작한 시점의 작업 트리와 비교한다. 세션 전부터 있던 변경은 대상이 아니다.
- 같은 지적으로는 세션마다 한 번만 막는다. 새 지적이 생기면 다시 막는다.
- 코드 블록과 인라인 코드 안의 마커는 예시로 보고 검사하지 않는다.

### 설치

bash(Windows는 Git Bash), Python 3.8 이상, git이 필요하다.
훅은 `python3`, `python`, `py` 순서로 Python을 찾는다.

```
claude plugin marketplace add utact/tackroom
claude plugin install kowrite@tackroom
```

## 테스트

```
python -m unittest discover -s tests
```

- `test_regressions.py`: 발견한 결함을 입력 그대로 남긴다.
- `test_rules.py`: 규칙마다 차원과 값을 정하고 곱집합으로 검사한다. 훅의 목록에 사례가 없는 값이 생기면 실패한다.
- `test_metrics.py`: 올바른 글의 오탐률과, 문장을 어절마다 끊은 변형의 재현율을 잰다. 재현율 하한은 올리기만 한다.
- `test_state.py`: 훅 상태가 한도 안에 머물고 작업 트리에 드러나지 않는지 확인한다.
- `test_stacks.py`: 기술 스택 조사 문서가 목록과 일치하고 양식을 갖췄는지 확인한다.
