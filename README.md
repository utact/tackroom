개인용 Claude Code 플러그인 저장소다.

## kowrite

한국어 문서·주석·커밋의 규칙을 세션 시작 때 지시하고, 지키지 않으면 훅으로 막는다. 모델을 호출하지 않는다.

| 규칙 | 지시 | 보증 |
|---|---|---|
| 문장은 짧게 쓰고, 한 문장이 끝나면 줄을 바꾼다. | 세션 시작 | 줄바꿈을 편집 직후 피드백하고, 커밋 직전과 종료 전에 막는다. |
| 커밋 메시지에 도구·모델 표기를 넣지 않는다. | 세션 시작 | 커밋 직전에 막는다. |
| 문서의 수치는 `<!-- const: 경로:상수 -->숫자`로 코드 상수와 묶는다. | 세션 시작 | 값이 다르면 편집 직후 피드백하고 종료 전에 막는다. |
| 코드를 설명하는 문서는 `<!-- tracks: 경로 -->`로 대상을 밝힌다. | 세션 시작 | 대상 코드만 바뀌면 종료 전에 막는다. |

지시는 네 줄이다. 지시를 지키면 훅은 아무것도 출력하지 않는다. 종료 전 차단은 세션마다 한 번이다.

Python과 git이 PATH에 있어야 한다.

```
claude plugin marketplace add C:/tackroom
claude plugin install kowrite@tackroom
```
