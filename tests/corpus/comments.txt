# 한 블록은 빈 줄로 나눈다. 블록 안의 줄은 주석에서 연달아 나오는 줄이다.
# 모든 줄은 올바르게 쓴 주석이다. 오탐률은 이 파일에서 잰다.
만료 파일 삭제
캐시 초기화
설정 파일 경로
요청 헤더 추가
응답 결과 확인

토큰이 만료되면 새로 발급한다.
발급에 실패하면 로그인 화면으로 보낸다.

사용자 권한 검사
관리자만 삭제할 수 있다.

재시도 횟수 제한
네트워크 오류일 때만 다시 시도한다.
세 번 실패하면 예외를 던진다.

페이지 크기 기본값
한 페이지에 20개씩 보여준다.

메시지 큐 연결 유지
연결이 끊기면 5초 뒤 다시 연결한다.

중복 요청 방지
같은 키로 들어온 요청은 한 번만 처리한다.

이미지 크기 조정
원본 비율을 유지한다.

파일을 읽는 동안 잠금을 건다.
다른 프로세스가 같은 파일을 쓰지 못하게 한다.

입력값 검증
빈 문자열은 허용하지 않는다.
공백만 있는 문자열도 빈 값으로 본다.

정렬 순서
최신 항목이 먼저 온다.

DB 트랜잭션 경계
이 함수 안에서 커밋하지 않는다.
호출한 쪽이 커밋을 책임진다.

환경 변수에서 읽은 값
없으면 기본값을 쓴다.

로그 수준 설정
운영 환경에서는 INFO 이상만 남긴다.

타임아웃 30초
외부 API 응답을 기다리는 최대 시간이다.

캐시 키 규칙
사용자 ID와 버전을 함께 넣는다.
버전이 바뀌면 이전 캐시는 쓰지 않는다.

테스트용 고정 시각
실제 시계를 쓰지 않는다.

변경 이력 기록
누가 언제 바꿨는지 남긴다.

목록 조회 API
삭제된 항목은 결과에서 뺀다.

배치 작업 진입점
실패한 항목은 따로 모아 다시 처리한다.

이 값은 문서와 같아야 한다.
바꾸면 README도 함께 고친다.
