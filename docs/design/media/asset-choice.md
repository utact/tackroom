# 벡터·래스터·사진·생성 이미지

확인: 2026-10-04.

## 요약

그래픽의 역할과 편집 요구에 맞춰 벡터·래스터·사진·생성 이미지를 비교한다.

## 문제 신호

삽화·재질을 단순 도형으로 억지로 만들거나 모든 그래픽을 이미지 하나로 고정한다.

## 기준선의 한계

한 매체만 쓰면 형태 편집·정교한 질감·다양한 크기·접근성 요구를 함께 충족하기 어렵다.

## 원리

벡터는 경로·도형을, 래스터는 픽셀을 보존한다. 제작 방식과 배포 형식은 별개다. 생성 도구는 사용 가능한 기능·편집·출력 조건을 확인하고 기존 자산과 비교한다.

## 가치

표현 품질과 변경 비용을 현재 그래픽의 역할에 맞춘다.

## 트레이드오프와 리스크

벡터도 경로·필터가 많으면 비싸다. 래스터는 해상도·알파·압축·크롭에 영향을 받는다. 출처와 원본 자산·생성 서비스의 사용 조건을 확인한다.

## 대안과 경계

기존 자산·공식 아이콘·단순 도형이 기준선이다. 복잡한 재질·사진·삽화는 적합한 원본과 제작 방식을 비교한다.

## 깊이 있는 활용

실루엣·화풍·색·사용 크기를 정한 뒤 원본·수정본·배포본을 연결한다.

## 임시방책의 신호

전체 화면을 한 이미지로 넣거나 작은 래스터 자산을 무제한 확대한다.

## 실패 재현

실제 작은 표시 크기·고밀도 화면·밝고 어두운 배경에서 같은 그래픽을 비교한다.

## 측정과 검증

실루엣, 편집 가능성, 압축 손상, 대체 텍스트와 로딩 비용을 확인한다.

## 재검토 조건

사용 크기·편집 빈도·상호작용이 바뀌면 매체와 출력 형식을 재검토한다.
