# 절차적 그래픽·생성 배경

확인: 2026-10-04.

## 요약

형태 규칙으로 그래픽을 만들고 제작·저장·실시간 표시 중 생성할 위치를 선택한다.

## 문제 신호

구름·나무·풍경의 변형이 많거나 연속 스크롤 배경이 필요하다.

## 기준선의 한계

완성 이미지를 복제하면 변형 범위가 좁고 생성 의도를 수정하기 어렵다.

## 원리

규칙·매개변수·시드로 형태를 구성하고 벡터·래스터 등으로 출력한다. [Shan Shui·Fishdraw](../../algorithms/generation/procedural-illustration.md)의 생성 규칙과 출력·청크 구조를 구분한다.

## 가치

적은 규칙으로 변형을 제작하고 출력 형식·화풍을 바꿀 수 있다.

## 트레이드오프와 리스크

많은 선·청크·실시간 계산은 표시·메모리 비용이 된다. 랜덤 출력이 원하는 실루엣·재현성을 보장하지 않는다.

## 대안과 경계

수작업·사전 생성 자산이 기준선이다. 실시간 변화가 필요하면 클라이언트 생성·셰이더를 비교한다.

## 깊이 있는 활용

생성·스타일·표시를 분리하고 같은 시드의 결과와 청크 수명을 정한다.

## 임시방책의 신호

오픈소스 예제의 외형만 보고 메모리 관리·애니메이션까지 완성됐다고 가정한다.

## 실패 재현

극단 매개변수·작은 해상도·긴 왕복 스크롤에서 결과와 비용을 관찰한다.

## 측정과 검증

시드 재현, 형태 오류, 청크 수, 생성·표시 시간과 보관 비용을 확인한다.

## 재검토 조건

실시간 편집·애니메이션·저사양 기기 지원이 필요하면 생성 시점과 출력 형식을 재검토한다.
