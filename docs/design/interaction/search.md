# 검색·자동완성·필터

확인: 2026-10-04.

## 요약

검색 입력, 추천 후보의 선택, 결과 필터를 별도 역할로 설계한다.

## 문제 신호

입력 중 첫 후보가 자동 확정되거나 필터를 지운 뒤 검색 범위를 알 수 없다.

## 기준선의 한계

검색창 외형과 요청 지연만 조절하면 후보 탐색·선택·빈 결과를 처리하지 못한다.

## 원리

Combobox는 입력과 연결된 팝업의 역할·선택·초점을 정의한다. 결과 목록, 필터 상태와 확정된 질의를 구분하고 오래된 응답을 처리한다.

## 가치

사용자가 무엇을 검색했고 어떤 조건이 결과에 적용됐는지 이해한다.

## 트레이드오프와 리스크

자동완성 방식에 따라 키보드 동작이 다르다. 후보가 많다고 전체 목록을 무조건 보조기술에 알리지 않는다.

## 대안과 경계

단순 제출형 검색을 기준선으로 삼는다. 후보 선택이 유용한 경우 자동완성을 비교한다.

## 깊이 있는 활용

필터 표시·초기화·결과 수·URL 복원과 입력 중 상태를 연결한다.

## 임시방책의 신호

팝업이 열렸다는 표시만 만들고 선택한 후보와 입력 값을 구분하지 않는다.

## 실패 재현

한글 조합, 빠른 질의 변경, 느린 응답, 후보 없음과 선택 취소를 재현한다.

## 측정과 검증

질의·결과 일치, 선택 확정, 초점 유지와 뒤로 이동 시 복원을 확인한다.

## 재검토 조건

검색 대상·필터 계층·추천 비용이 바뀌면 입력과 결과 구조를 재검토한다.
