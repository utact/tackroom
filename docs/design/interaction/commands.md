# 버튼·메뉴·추가 작업

확인: 2026-10-04.

## 요약

즉시 실행하는 버튼과 선택지를 여는 메뉴를 구분하고 행동의 중요도에 맞춰 노출한다.

## 문제 신호

주요 행동이 점 세 개 메뉴 안에 숨거나 아이콘만 보고 삭제와 이동을 구분해야 한다.

## 기준선의 한계

모든 행동을 같은 버튼 모양으로 표시하면 우선순위와 결과를 알기 어렵다.

## 원리

버튼은 행동을 실행하고 링크는 자원으로 이동한다. 메뉴 버튼은 메뉴의 열림 상태와 키보드 동작을 제공한다. 추가 작업 메뉴·문맥 메뉴에는 해당 대상의 행동을 묶는다.

## 가치

많은 명령 중 자주 쓰는 행동을 발견하고 실행 결과를 예상한다.

## 트레이드오프와 리스크

호버·오른쪽 클릭만으로 제공한 명령은 터치에서 발견하기 어렵다. 웹 탐색 링크 묶음에 menu 역할을 붙이면 추가 키보드 계약이 생긴다.

## 대안과 경계

짧은 목록은 보이는 버튼·링크를 유지한다. 덜 쓰는 행동에 추가 작업 메뉴를 비교한다.

## 깊이 있는 활용

행동의 대상·빈도·되돌리기 가능성을 정하고 이름과 강조를 맞춘다. 실행 이름과 안내 문구는 [UI 문구 카드](ui-copy.md)로 검토한다.

## 임시방책의 신호

중요한 행동을 공간 부족만으로 숨기거나 메뉴가 열려도 초점을 옮기지 않는다.

## 실패 재현

키보드·터치로 메뉴를 열고 항목 실행·취소·원래 버튼 복귀를 확인한다.

## 측정과 검증

행동 발견, 접근성 이름, 펼침 상태와 실행 대상의 정확성을 확인한다.

## 재검토 조건

명령 수·사용 빈도·되돌리기 비용이 바뀌면 노출과 묶음을 재검토한다.
