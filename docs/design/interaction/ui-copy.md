# UI 문구와 행동 레이블

확인: 2026-10-04.

## 요약

UI 문구(UI Copy)는 현재 상황·행동·결과를 설명한다. 버튼 레이블은 실행할 행동을 짧고 구체적으로 표시한다.

## 문제 신호

‘확인’을 누르면 저장인지 삭제인지 알 수 없거나 제목·본문·버튼이 같은 내용을 반복한다.

## 기준선의 한계

중립적인 단어만으로 짧게 쓰면 손실 범위나 다음 행동이 모호해질 수 있다.

## 원리

제목은 상황을 알리고 본문은 추가로 필요한 결과·조건을 설명한다. 버튼은 ‘프로젝트 삭제’처럼 행동을 명시하고 취소 경로를 구분한다. 순수 정보 확인에는 ‘확인’이 적합할 수 있다.

## 가치

사용자가 실행 전에 결과를 예상하고 오류 이후의 행동을 찾을 수 있다.

## 트레이드오프와 리스크

너무 짧으면 대상을 잃고 길면 읽기·번역·배치 부담이 커진다. 사용자를 탓하거나 손실을 가볍게 표현하지 않는다.

## 대안과 경계

플랫폼의 명칭·문구 관례를 기준선으로 삼는다. 제품 UI에 조사 표의 명사 종결이나 커밋 작성 형식을 일괄 적용하지 않는다.

## 깊이 있는 활용

‘프로젝트를 삭제하면 포함된 파일도 삭제됩니다.’처럼 추가 영향이 있을 때 설명한다. 화면에 이미 분명한 대상은 레이블에서 불필요하게 반복하지 않는다.

## 임시방책의 신호

‘정말’, ‘주의’만 더하거나 내부 오류 코드·팀 별칭을 사용자의 행동 안내로 쓴다.

## 실패 재현

버튼 레이블만 읽어도 행동을 알 수 있는지, 본문을 읽으면 추가 결과를 이해하는지 긴 번역에서도 확인한다.

## 측정과 검증

대상·행동·결과의 이해, 보이는 이름과 접근성 이름의 일치, 잘림과 중복 표현을 확인한다.

## 재검토 조건

데이터 영향·번역·플랫폼이 바뀌면 문구와 실제 동작을 함께 검토한다.
