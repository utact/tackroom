# 글래스모피즘·반투명 소재

확인: 2026-10-04.

## 요약

글래스모피즘(Glassmorphism)은 배경을 비추는 반투명 표면으로 계층을 표현한다. CSS 구현과 Apple의 Liquid Glass는 구현·용도가 다르다.

## 문제 신호

풍부한 배경 위에 조작부를 올리면서 배경의 맥락도 유지하려 한다.

## 기준선의 한계

투명도만 낮추면 배경의 세부가 글자와 겹쳐 읽기 어려울 수 있다.

## 원리

웹 backdrop-filter는 뒤 영역을 흐리거나 색을 바꾸며 투명한 표면에서 효과가 보인다. Apple은 Liquid Glass를 주로 조작·탐색 계층에, 표준 소재를 콘텐츠 계층에 안내한다.

## 가치

배경과 조작 계층의 관계를 유지하며 깊이를 표현한다.

## 트레이드오프와 리스크

움직이는 배경·넓은 흐림 영역의 비용과 대비를 확인한다. 투명도 감소·대비 강화 설정과 미지원 환경에 불투명 대체를 제공한다.

## 대안과 경계

불투명 표면이 기준선이다. 네이티브에서는 시스템 소재를, 웹에서는 CSS 효과와 사전 제작 자산을 비교한다.

## 깊이 있는 활용

표면의 색·불투명도·흐림을 배경 조건별로 조정하고 필수 정보의 대비를 유지한다.

## 임시방책의 신호

모든 카드에 같은 blur를 붙이거나 시스템 Liquid Glass를 CSS 한 속성으로 재현했다고 말한다.

## 실패 재현

밝고 어두운 영상·복잡한 사진 뒤에 텍스트를 놓고 투명도 감소 설정을 켠다.

## 측정과 검증

최악 배경의 가독성, 상태 구분, 스크롤 프레임 비용과 대체 표현을 확인한다.

## 재검토 조건

배경 매체·OS·지원 브라우저가 바뀌면 소재와 적용 범위를 재검토한다.
