# 클레이모피즘·부푼 형태

확인: 2026-10-04.

## 요약

클레이모피즘(Claymorphism)은 둥글고 부푼 형태를 CSS 음영이나 별도 그래픽 자산으로 표현한다.

## 문제 신호

놀이·교육·브랜드 삽화에 부드러운 입체 형태가 필요하다.

## 기준선의 한계

큰 모서리 반경 하나만으로는 부피감이나 일관된 광원을 만들기 어렵다.

## 원리

clay.css의 구현은 배경·반경·바깥 그림자 하나·안쪽 그림자 둘을 조합한다. 3D 렌더 자산은 실제 곡면·조명을 다루는 별도 제작 방법이다.

## 가치

간단한 형태를 재사용하거나 캐릭터·장식 자산과 UI의 화풍을 맞춘다.

## 트레이드오프와 리스크

부푼 모양이 접근성을 자동 해결하지 않는다. 선택·초점·본문 대비는 따로 확인한다. clay.css package.json은 MIT로 표시하며 선택한 배포본의 고지를 확인한다.

## 대안과 경계

기존 둥근 컴포넌트가 기준선이다. CSS 표면과 렌더 이미지의 수정·표시 비용을 비교한다.

## 깊이 있는 활용

광원·곡률·색의 기준을 정하고 장식과 조작 영역의 역할을 구분한다.

## 임시방책의 신호

패딩과 그림자를 크게 늘려 조작 영역이 겹치거나 모든 요소를 같은 장난감 형태로 만든다.

## 실패 재현

좁은 화면·긴 문구·어두운 테마에서 경계와 그림자 겹침을 확인한다.

## 측정과 검증

실루엣, 광원 일치, 상태 전달과 실제 조작 영역을 확인한다.

## 재검토 조건

복잡한 실루엣·조명 변화·캐릭터 운동이 필요하면 별도 자산·3D 제작을 비교한다.
