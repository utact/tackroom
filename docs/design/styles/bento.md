# 벤토·카드 격자·편집형 배치

확인: 2026-10-04.

## 요약

벤토(Bento)는 크기가 다른 영역을 묶는 배치 표현이다. 질감이나 컴포넌트 동작 규약이 아니다.

## 문제 신호

제품 특징·대시보드 정보를 여러 블록으로 구성하려 한다.

## 기준선의 한계

모든 항목을 같은 카드에 넣으면 중요도와 항목 간 관계가 드러나지 않는다.

## 원리

CSS Grid 등으로 영역의 크기와 관계를 정한다. 편집형 배치는 서체·이미지·여백의 위계도 사용한다. 이름보다 콘텐츠 순서와 실제 작업이 우선이다.

## 가치

정보의 비중과 묶음을 시각적으로 전달한다.

## 트레이드오프와 리스크

시각적 재배치가 DOM 읽기 순서와 다르면 혼란을 만든다. 좁은 창에서 카드만 작게 줄이면 콘텐츠가 잘린다.

## 대안과 경계

단일 열·동일 격자가 기준선이다. 강조할 정보와 관계가 있을 때 비대칭 배치를 비교한다.

## 깊이 있는 활용

주요 정보의 순서를 먼저 정하고 넓은 창의 영역 크기와 좁은 창의 재배치를 설계한다.

## 임시방책의 신호

남은 칸을 채우려고 의미 없는 카드나 숫자를 넣는다.

## 실패 재현

큰 글자·긴 제목·좁은 창에서 시각 순서와 키보드·읽기 순서를 비교한다.

## 측정과 검증

콘텐츠 위계, 실제 순서, 잘림과 주요 행동의 발견을 확인한다.

## 재검토 조건

카드의 관계·정보량이 달라지면 격자와 단일 열의 비용을 다시 비교한다.

## 출처

- [MDN CSS Grid](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Grid_layout): 격자 배치. 벤토·편집형 적용 조건은 공식 용어 규격이 아닌 설계 판단이다.
