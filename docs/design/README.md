# UI·UX·시각 표현

현재 화면의 구조·동작·표현을 고를 때 쓰는 자료다. 플랫폼과 작업을 먼저 정하고 관련 카드만 읽는다.

## 판단 기준

- **요구사항**: 제공사 브랜드·서비스 조건과 채택한 접근성 기준의 적용 범위·예외
- **권장 관례**: 플랫폼에 익숙한 탐색·입력·상태·배치
- **인지·지각 원리**: 연구 과제와 적용 조건에 따른 선택·조작·그룹화·기억
- **표현 선택**: 제품 목적에 맞는 시각 스타일·그래픽·모션과 제작·재생 비용

햄버거는 메뉴 아이콘의 별칭이다. 사이드바·드로어·탭 바는 구성요소이며, 이를 조합한 이동 방식은 탐색 패턴이다. 글래스·클레이는 시각 스타일, 입자·종이는 표면 질감, 벤토는 배치 표현이다. 문서마다 분류 범위가 다르므로 통용 명칭과 실제 역할을 함께 확인한다.

기술·알고리즘 카드와 같은 조사 양식을 쓴다. 디자인의 원리는 역할·상태·표현 구조로, 반례는 다른 입력·배경·사용자 설정에서의 실패로 다룬다. 각 카드의 확인일은 출처 확인 시점이며, 실패 재현·측정 절은 적용 프로젝트에서 수행할 검증이다. 제품의 실행·사용자 평가 결과를 뜻하지 않는다.

이름에 ‘법칙’이 있어도 근거의 성격은 다르다. 실험 모델·설계 휴리스틱·지각 원리·기억 효과를 구분하고, 현재 과제에 적용할 근거와 한계를 확인한다.
