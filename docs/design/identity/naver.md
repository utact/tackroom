# 네이버 로그인 버튼

확인: 2026-10-04.

## 요약

현재 네이버 로그인 BI와 공식 자산을 기준으로 버튼을 구성한다.

## 문제 신호

과거 블로그의 색상이나 임의로 그린 N 심볼이 버튼에 남아 있다.

## 기준선의 한계

외부 예제의 브랜드 색을 복사하면 현재 로그인 지침과 다를 수 있다.

## 원리

확인한 가이드의 초록색은 #03A94D다. N 로고 형태와 지정 색을 유지하고 완성형·아이콘형 각각의 크기·여백 조건을 확인한다. 로그인 목적을 유지하는 문구 변경은 허용 범위를 따른다.

## 가치

오래된 예제 대신 제공사의 현재 자산과 화면 조건을 연결한다.

## 트레이드오프와 리스크

완성형과 아이콘형의 최소 크기가 다르다. 픽셀 기준 자산과 화면 밀도 변환을 구분한다.

## 대안과 경계

공식 PNG·AI·Figma 자산이 기준선이다. 다른 녹색 로고나 앱의 장식용 N은 대체하지 않는다.

## 깊이 있는 활용

좁은 버튼에서도 로고 위치와 레이블 정렬이 유지되는 배치를 고른다.

## 임시방책의 신호

다른 제공사 버튼과 같은 색으로 바꾸거나 인터넷에서 찾은 N 문자를 사용한다.

## 실패 재현

긴 레이블과 최소 크기에서 로고·문구·여백이 잘리는지 확인한다.

## 측정과 검증

현재 BI의 색·로고·크기 조건, 접근성 이름과 로그인 복귀 경로를 확인한다.

## 재검토 조건

BI 가이드·자산 배포가 바뀌면 저장한 자산과 사용 화면을 함께 갱신한다.
