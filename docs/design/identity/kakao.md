# 카카오 로그인 버튼

확인: 2026-10-04.

## 요약

카카오 로그인 버튼의 공식 구성과 허용 변형을 적용한다.

## 문제 신호

카카오 CI·카카오톡 아이콘을 로그인 심볼로 혼용하거나 노란색만 비슷하게 맞춘다.

## 기준선의 한계

제공사를 색으로만 표현하면 심볼·레이블·비율 지침을 놓친다.

## 원리

버튼은 심볼·레이블·컨테이너로 구성한다. 디자인 가이드의 컨테이너 색은 #FEE500이며 심볼의 형태·비율·색을 유지한다. 레이블과 축약형은 공식 허용 범위를 확인한다.

## 가치

한국어 서비스에서 익숙한 계정 진입을 공식 자산으로 제공한다.

## 트레이드오프와 리스크

카카오 로그인과 카카오 인증의 자산을 구분한다. 자산 픽셀 크기를 모든 화면의 dp·pt로 그대로 옮기지 않는다.

## 대안과 경계

공식 다운로드 자산을 기준선으로 삼고 사용자 정의가 필요하면 각 구성요소의 허용 범위를 확인한다.

## 깊이 있는 활용

축약·전체 레이블, 언어, 버튼 너비를 제공 화면의 다른 진입과 비교한다.

## 임시방책의 신호

말풍선 비슷한 도형을 직접 그리거나 앱의 공통 버튼 색으로 덮어쓴다.

## 실패 재현

버튼을 확대·축소하고 작은 화면에서 심볼·문구·여백 비율을 확인한다.

## 측정과 검증

공식 심볼 일치, 허용 색·문구, 접근성 이름과 로그인 취소 후 복귀를 확인한다.

## 재검토 조건

카카오 제품·자산·디자인 가이드가 바뀌면 해당 버튼을 재검토한다.
