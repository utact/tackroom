# 확산 제한 응집과 Physarum 입자 모델

확인: 2026-10-04.

## 요약

DLA는 무작위 이동 입자의 부착으로, Physarum 모델은 입자와 흔적 장의 상호작용으로 형태를 만든다. 분기 성장과 동적 연결망은 다른 갱신 규칙이다.

## 문제 신호

결정·서리 같은 분기 무늬나 유기적 길·연결망의 생성 과정을 탐색하려는 상황이다.

## 기준선의 한계

재귀 가지는 명시적 골격을 만들지만 입자 누적이나 흔적 장의 피드백을 표현하지 않는다. 형태 유사성은 물리적 정확성이나 최적 경로의 근거가 아니다.

## 원리

DLA의 기본 구성은 먼 영역에서 이동한 입자가 기존 군집에 닿으면 고정되는 성장이다. Jones의 Physarum 모델은 앞·좌·우 센서로 흔적을 읽고 방향을 조절해 이동·침적한다. 흔적 장은 확산·감쇠한다. 부착 규칙·센서 거리·회전·침적·경계는 서로 다른 제어값이다.

## 가치

입자 행동과 장의 피드백이 전체 모양을 바꾸는 것을 비교한다. 같은 외곽 조건에서 분기·연결·성장 비용의 차이를 관찰한다.

## 트레이드오프와 리스크

DLA는 군집이 커질수록 이동 비용이 커질 수 있다. 유한 경계와 입자 방출·폐기 규칙이 결과에 영향을 준다. Physarum의 연결망은 항상 최단·최소 비용이라는 보장이 없다.

## 대안과 경계

[Space colonization](branching.md)은 목표 수관을 제어하는 대안이다. 그래프 최적화는 명시적 최적 경로가 필요한 경우의 대안이며 모양 생성과 목적이 다르다.

## 깊이 있는 활용

원천·장애물·먹이 자극을 상태 장과 분리해 실험한다. 입자 수·흔적 갱신과 화면 색 매핑을 분리해 결과의 원인을 추적한다.

## 임시방책의 신호

입자 이동 한도를 늘리며 멈춤 문제를 숨기거나, 보기 좋은 네트워크를 최적이라고 보고한다. 모델마다 다른 확산·부착 규칙을 같은 설명으로 묶는다.

## 실패 재현

입자가 군집에 못 닿는 경계, 밀집 군집, 흔적의 감쇠 제거·과대 침적, 센서 거리 변경을 비교한다.

## 측정과 검증

부착까지의 이동 횟수, 군집 크기·분기 수, 연결 성분·경로 길이, 장의 범위, 입자·격자 수별 시간과 메모리를 기록한다.

## 재검토 조건

종료·최적성·목표 모양이 필수라면 제약 생성·명시적 그래프 알고리즘과 비교한다.

## 출처

- [Witten·Sander, Diffusion-Limited Aggregation, 1981](https://journals.aps.org/prl/abstract/10.1103/PhysRevLett.47.1400): 원논문 초록의 성장 모델과 관찰 범위.
- [Witten의 DLA 회고, 1993](https://garfield.library.upenn.edu/classics1993/A1993KX31200001.pdf): 원저자의 무작위 이동·부착 모델 설명을 확인했다.
- [Jones, Complex Transport Networks, 2015 공개본, §2](https://arxiv.org/pdf/1503.06579): 센서·이동·흔적 침적·확산·감쇠의 의사코드를 확인했다. 최적성 증명 자료로 사용하지 않는다.
