# De Bruijn 수열

확인: 2026-10-04.

## 요약

크기 k의 알파벳에서 길이 n인 모든 단어가 순환 창에 한 번씩 나타나는 수열이다. 짧은 순환 자극으로 전체 조합을 순회하는 성질을 조사한다.

## 문제 신호

최근 n개의 입력 조합을 모두 검사하거나 고정 길이 패턴의 출현을 빠짐없이 관찰하려는 상황이 활용 가설이다.

## 기준선의 한계

모든 단어를 각각 전송하면 중첩 가능한 접미·접두 부분을 반복한다. 무작위 입력은 유한 실행에서 모든 조합의 출현을 보장하지 않는다.

## 원리

수열의 순환 길이는 kⁿ이다. 길이 n−1 단어를 정점으로, 길이 n 단어를 간선으로 둔 De Bruijn 그래프의 오일러 순회를 이용해 구성할 수 있다. 선형 입력으로 사용할 때는 끝에 시작 부분 n−1개를 덧붙여 순환 창을 복원한다.

## 가치

전체 창 조합을 압축된 순회 형태로 관찰하며 오일러 경로와 중첩 구조를 배운다. 센서·패턴 입력 검사의 활용 효과는 검사 모델에 맞춰 확인한다.

## 트레이드오프와 리스크

길이는 여전히 n에 대해 지수적으로 증가한다. 길이 n 창의 완전성은 더 긴 내부 상태나 시간 의존 조건의 검증을 대신하지 않는다.

## 대안과 경계

작은 범위의 명시적 조합 목록은 읽기 쉽다. [Gray code](gray-code.md)는 상태 사이의 변화량을 줄이는 대안이며 창 조합의 완전성과는 다른 성질이다.

## 깊이 있는 활용

모든 단어 대신 허용된 단어만 순회하려면 제한된 그래프의 연결성과 오일러 조건을 다시 확인한다. 온라인 생성과 전체 수열 보관의 메모리 차이를 비교한다.

## 임시방책의 신호

선형 수열의 순환 경계를 검사하지 않거나, 창 완전성을 전체 시스템 테스트 완료로 보고한다. 입력 길이의 지수적 증가를 누락한다.

## 실패 재현

이진 n=3 예제에서 순환 창 여덟 개의 중복·누락을 센다. 접두부를 덧붙이지 않은 선형 입력과 금지 단어를 임의로 삭제한 수열을 비교한다.

## 측정과 검증

길이, 창별 출현 횟수, 생성 시간, 작업 메모리를 측정한다. 실제 테스트에서는 입력을 소비하는 시스템의 상태 길이와 리셋 조건을 함께 기록한다.

## 재검토 조건

알파벳·창 길이·금지 조합이 바뀌면 구성 조건을 재검토한다. 전체 순회가 불가능한 범위에서는 표본 검사와 검증 범위의 제한을 명시한다.
