# 콜라츠 수열

확인: 2026-10-04.

## 요약

양의 정수에 짝수 n/2, 홀수 3n+1 규칙을 반복한다. 궤적의 굴곡과 합류를 관찰하는 수학적 소재이며, 모든 입력의 1 도달을 전제로 사용하는 생성 알고리즘은 아니다.

## 문제 신호

간단한 결정 규칙의 결과를 탐색하거나, 여러 궤적의 공통 경로를 표현하려는 상황이 활용 가설이다. 현재 활용처가 정해지지 않아도 조사 대상으로 보존한다.

## 기준선의 한계

주기 수열·난수 배열과 다른 결정적 궤적을 만든다. 그러나 규칙이 짧다는 사실은 길이·분포·종료를 원하는 대로 제어할 수 있다는 뜻이 아니다.

## 원리

홀수 직후의 나눗셈을 합치지 않는 정의를 사용한다. 같은 값에 도달하면 이후 경로가 같다는 성질은 결정성에서 따른다. 모든 양의 정수가 1에 도달한다는 것은 별도의 추측이다. 1에서 계속 갱신하면 1→4→2→1이 반복된다.

## 가치

규칙에서 따르는 성질, 유한 계산, 수학적 추측을 구분하는 학습 사례다. 역방향 관계나 여러 시작값의 합류를 시각화하는 활용은 출력 매핑을 추가한 가설이다.

## 트레이드오프와 리스크

입력에 대한 종료·계산량 상한이 보장되지 않는다. 정수 오버플로와 반복 상한을 다루며, 공통 꼬리 때문에 시작값 개수가 출력 다양성과 같지 않음을 확인한다.

## 대안과 경계

[Thue–Morse](thue-morse.md)는 규칙과 반복 제한이 명확한 다른 수열이다. 난수는 분포 제어가 필요한 경우의 비교 대상이며 콜라츠를 균일 난수로 취급하지 않는다.

## 깊이 있는 활용

합류한 경로를 공유하는 그래프 표현을 만들 수 있다. 정방향 다음 값은 하나이므로 그림의 분기는 역방향 관계인지 여러 경로의 합류인지 밝힌다. 가속 변형과 비교할 때 단계 수의 정의를 맞춘다.

## 임시방책의 신호

모든 입력에서 1을 기다리는 무제한 루프를 만들거나, 짧은 계산 결과로 전체 추측을 해결했다고 쓴다. Tao의 부분 결과를 전체 종료 보장으로 사용한다.

## 실패 재현

27을 10회만 갱신해 계산 한도 도달과 발산을 구분한다. 고정 폭 정수와 임의 정밀도 정수의 결과를 큰 입력에서 비교한다. 6과 3의 경로 합류를 확인한다.

## 측정과 검증

2026-10-04 Windows Python 3.12.12에서 1·3·6·7·27을 최대 1,000회, 처음 1 도달 시 종료하는 규칙으로 실행했다. 갱신 횟수는 각각 0·7·8·16·111, 최대값은 1·16·16·52·9,232였다. 6의 첫 단계 이후는 3의 전체 경로와 일치했다. 27을 10회 제한하면 마지막 값은 214였고 1에 도달하지 않았다.

재현 시 `n = n // 2 if n % 2 == 0 else 3 * n + 1`을 정수로 계산하고 시작값을 0번째 상태로 센다. 이 관찰은 입력 다섯 개와 제한 계산 한 건에 한정되며 분포·성능·전체 종료의 검증이 아니다.

## 재검토 조건

출력 길이·중복률·제어성이 요구되면 다른 수열과 비교한다. 생성 규칙이나 표현 매핑이 바뀌면 재현 조건을 다시 기록한다.
