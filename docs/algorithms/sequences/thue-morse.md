# Thue–Morse 수열

확인: 2026-10-04.

## 요약

0→01, 1→10 치환을 반복하거나 이진 자리수 합의 홀짝으로 만드는 결정적 수열이다. 단순 반복·무작위와 다른 반복 제한을 조사한다.

## 문제 신호

같은 작은 규칙에서 재현 가능한 비주기적 순서를 만들고, 특정 반복 패턴의 부재를 관찰하려는 상황이 활용 가설이다.

## 기준선의 한계

짧은 주기의 반복은 금방 드러나며 무작위 배열은 원하는 반복 제한을 보장하지 않는다. 비주기성만으로 시각적 다양성이나 공정성을 설명할 수 없다.

## 원리

t₀=0, t₂ₙ=tₙ, t₂ₙ₊₁=1−tₙ이다. n의 이진 표현에서 1의 개수의 홀짝과도 같다. overlap-free 성질은 a가 한 기호이고 w가 단어일 때 awawa 형태가 없다는 뜻이며, 모든 부분 단어가 한 번만 나타난다는 뜻이 아니다.

## 가치

재귀 정의·기호 치환·자리수 계산이 같은 결과를 만드는 것을 실험한다. 소리·문양·입력 순서를 만드는 활용은 표현 규칙을 추가한 별도 가설이다.

## 트레이드오프와 리스크

유한 출력에는 부분 패턴의 반복이 있다. 기호를 다른 출력으로 병합하면 원래의 반복 제한이 사라질 수 있다. 균일 난수나 보안 난수로 사용하지 않는다.

## 대안과 경계

주기 수열과 난수 배열은 단순한 비교 대상이다. [De Bruijn 수열](de-bruijn.md)은 창 조합을 모두 나타내는 목적이며 서로 대체 보장이 아니다.

## 깊이 있는 활용

전체 접두부를 저장하지 않고 순번의 비트 개수로 원하는 항목을 구한다. 이진 기호의 시각·음향 대응을 바꿔 성질이 출력에서 보존되는지 검사한다.

## 임시방책의 신호

비주기 수열을 반복이 전혀 없는 수열이라고 쓰거나, 기호 수가 같다는 이유로 모든 사용 맥락에서 공정하다고 주장한다.

## 실패 재현

치환 방식과 자리수 홀짝 방식으로 같은 길이의 접두부를 만든다. 출력 기호를 하나로 합쳤을 때 제한이 무너지는 사례를 만들고 유한 길이의 overlap 검사를 수행한다.

## 측정과 검증

두 생성법의 일치, 접두부의 기호 빈도, 검사한 길이 내 금지 패턴, 출력 매핑 후 중복률을 기록한다. 유한 검사는 정리의 증명과 구분한다.

## 재검토 조건

순서를 바꾸거나 기호 매핑·연결 규칙을 바꾸면 원래 성질이 보존되는지 다시 확인한다. 단순한 반복만 필요하면 규칙의 추가 부담을 비교한다.

## 출처
