# 반복 함수계와 복소 반복 프랙탈

확인: 2026-10-04.

## 요약

IFS는 여러 수축 변환의 반복으로, Mandelbrot 집합은 복소 이차 반복의 유계성으로 정의되는 서로 다른 구조다. 작은 규칙과 풍부한 경계·자기 유사 표현의 관계를 조사한다.

## 문제 신호

적은 변환으로 형태를 기술하거나 확대·반복에 따른 세부를 탐색하려는 경우가 활용 가설이다. 두 방식을 동일한 프랙탈 생성기로 취급하지 않는다.

## 기준선의 한계

손으로 그린 반복 조각은 규칙과 생성 결과가 분리되어 있다. 단순한 도형 반복은 변환 선택이나 발산 경계의 구조를 표현하지 않는다.

## 원리

IFS는 공간의 수축 사상 집합으로 불변 집합을 정의하며 chaos game은 변환을 표본 추출해 점을 만든다. Mandelbrot는 z₀=0, zₜ₊₁=zₜ²+c의 궤적이 유계인 c의 집합이다. 유한 반복에서 발산하지 않았다는 관찰만으로 포함을 확정하지 않는다.

## 가치

변환 규칙의 저장과 유한 점 표본의 차이, 반복 상한과 경계 화질의 관계를 실험한다. 모양의 학습과 실제 자산 제작 가능성을 따로 평가한다.

## 트레이드오프와 리스크

IFS의 수축 조건을 깨면 기대하는 불변 집합 설명이 적용되지 않는다. chaos game의 확률은 점의 관찰 밀도에 영향을 준다. 복소 반복의 깊은 확대는 정밀도와 계산 비용을 요구한다.

## 대안과 경계

벡터 도형·래스터 자산은 제어가 쉬운 대안이다. [L-system 기반 분기](../generation/branching.md)는 문법 규칙을 사용하는 다른 형태 표현이다.

## 깊이 있는 활용

IFS의 변환과 확률을 따로 조절해 형태와 표본 밀도를 분리한다. 복소 반복에서는 반복 상한·좌표 정밀도·색 매핑을 분리하고 확대 단계마다 확인한다.

## 임시방책의 신호

finite escape-time 그림을 정확한 집합 판정이라고 쓰거나, 점의 빈도가 높은 부분을 면적이 큰 구조라고 설명한다. 수축 조건 없이 동일한 수렴을 기대한다.

## 실패 재현

수축 변환 하나를 확대 변환으로 바꾼 IFS를 비교한다. 같은 복소 좌표를 반복 상한과 정밀도를 바꾸어 분류하고 경계 결과가 달라지는지 관찰한다.

## 측정과 검증

변환별 표본 수, 과도 단계 제거, 이미지 해상도·반복 횟수·좌표 정밀도별 비용과 결과 일치를 기록한다. 미탈출 픽셀은 미확정으로 표시한다.

## 재검토 조건

확대 깊이, 편집 요구, 실루엣 제어가 바뀌면 규칙 기반 출력과 명시적 자산을 비교한다.
