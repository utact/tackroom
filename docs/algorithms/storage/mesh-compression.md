# 메시 양자화·압축·재정렬

확인: 2026-10-04.

## 요약

기하 값의 정밀도, 배포 부호, GPU 접근 순서를 각각 바꾼다. Draco는 메시·점군 압축을 제공하며 meshoptimizer는 재정렬·단순화·부호화 등 여러 연산을 제공한다.

## 문제 신호

큰 기하 자산의 전송·복원·렌더링 부담을 줄이거나, 생성한 메시의 정밀도와 메모리를 비교하려는 경우다.

## 기준선의 한계

실수 속성과 원래 인덱스를 그대로 저장하면 구조를 활용하지 않는다. 범용 파일 압축은 배포 크기를 줄일 수 있지만 GPU의 정점 재사용 순서는 바꾸지 않는다.

## 원리

양자화는 속성 범위의 값을 제한된 격자에 옮기므로 오차를 만든다. 압축은 속성·인덱스 상관을 부호화한다. 재정렬은 삼각형과 정점 접근의 지역성을 바꾸고 인덱스를 함께 갱신한다. meshoptimizer의 정점 부호와 인덱스 부호는 입력 표현·순서의 조건을 확인해야 한다.

## 가치

전송량과 렌더링 접근의 개선을 독립적으로 실험한다. 같은 자산에서 정밀도 예산과 품질을 연결하기 쉽다.

## 트레이드오프와 리스크

위치 오차는 균열·충돌·애니메이션에 영향을 줄 수 있다. 속성 연결을 함께 바꾸지 않으면 색·UV·스킨이 어긋난다. 인덱스 부호화의 삼각형 회전은 provoking vertex에 영향을 줄 수 있다.

## 대안과 경계

기하가 적으면 원본과 [범용 압축](lossless-codecs.md)이 충분할 수 있다. 텍스처 상주량은 [GPU 텍스처](gpu-textures.md)의 문제다. 재정렬의 GPU 효과와 압축률을 같은 개선 수치로 합치지 않는다.

## 깊이 있는 활용

위치·법선·UV의 허용 오차를 따로 정하고, 재정렬 후 압축하는 순서를 비교한다. 그림자용 인덱스나 여러 세부 수준의 속성 연결도 함께 검사한다.

## 임시방책의 신호

작은 파일만으로 렌더링이 빨라졌다고 주장하거나, 정점 순서에 의존하는 외부 데이터를 갱신하지 않는 경우다.

## 실패 재현

제안 실험: 경계가 맞닿은 두 메시와 평면 속성이 다른 삼각형을 준비한다. 양자화·재정렬·압축을 각각 적용해 균열과 속성 연결, flat shading의 변화를 확인한다.

## 측정과 검증

복원 속성 오차, 파일·버퍼 크기, 복원·업로드·GPU 시간과 참조 일치를 측정한다. 기기와 셰이더를 고정한다. Draco·meshoptimizer를 실행한 결과는 없다.

## 재검토 조건

스킨·모프·외부 정점 참조가 추가되면 순서 보존 요구를 검토한다. 양자화 범위·압축 버전이 바뀌면 자산 호환성과 품질을 재검증한다.

## 출처

- [Draco 공식 설명](https://github.com/google/draco): 속성별 양자화 비트, 압축 수준과 메시·점군 경로를 확인했다.
- [meshoptimizer 공식 설명](https://github.com/zeux/meshoptimizer): 정점 재사용·접근 재정렬, 인덱스 부호화의 입력 조건과 삼각형 회전 주의를 확인했다. 기본 브랜치 자료이며 성능 수치를 재현하지 않았다.
