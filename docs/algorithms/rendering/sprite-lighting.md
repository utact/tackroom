# 스프라이트 노멀 맵과 2D 조명

확인: 2026-10-04.

## 요약

그림에 표면 방향 정보를 추가해 조명이 움직일 때 명암이 달라지게 한다. 노멀 맵은 조명 계산을 바꾸며 실루엣과 충돌 형상을 자동으로 만들지 않는다.

## 문제 신호

스프라이트의 요철·재질을 동적 조명으로 읽게 하거나, 색 그림과 조명 정보를 따로 관리하려는 경우다.

## 기준선의 한계

명암을 색 그림에 고정하면 광원 방향이 바뀌어도 그림 속 빛은 그대로 남는다. 평면의 법선 하나만 쓰면 작은 표면 방향 차이가 드러나지 않는다.

## 원리

색 텍스처와 정렬된 노멀 텍스처에서 표면 방향을 읽고 광원 방향 등과 결합한다. 좌표계·축 방향·색 공간·UV가 맞아야 한다. Unity URP 2D에서는 지원 재질, Secondary Texture, 광원의 노멀 사용 설정을 함께 구성한다.

## 가치

한 색 자산을 여러 조명 환경에 사용할 수 있다. 노멀·마스크·색의 역할을 분리해 재질 표현의 원리를 관찰한다.

## 트레이드오프와 리스크

프레임마다 노멀 자산을 맞추는 제작 비용이 생긴다. 빛이 이미 그려진 그림과 새 명암이 충돌할 수 있다. Unity 6000.6 문서는 층 배치별 깊이 사전 패스와 전체 크기 렌더 텍스처 비용을 명시한다.

## 대안과 경계

정적 조명은 미리 그린 명암이 더 단순하다. 가림은 별도 그림자·기하 조건이다. 시점에 따른 표면 위치 변화는 [변위 매핑](displacement.md)을 비교한다.

## 깊이 있는 활용

절차적 높이 장에서 법선을 유도하고 같은 색 자산에 서로 다른 요철을 시험할 수 있다. 높이 장의 연속성, 미분 간격, 경계 처리를 기록해 조명 변화의 원인을 추적한다.

## 임시방책의 신호

빛 반응이 틀릴 때 밝기만 조정하거나, 뒤집힌 축과 잘못된 색 공간을 자산마다 예외로 보정하는 경우다.

## 실패 재현

제안 실험: 평면 노멀과 일정하게 기울어진 노멀을 같은 그림에 적용하고 광원을 회전한다. UV를 한 칸 이동하거나 노멀 축을 뒤집은 변형에서 요철과 색이 어긋나는지 확인한다.

## 측정과 검증

광원 방향별 명암, 자산 정렬, 애니메이션 프레임의 일관성과 GPU 비용을 확인한다. 노멀 사용 전후에 층·광원 수와 해상도를 고정한다. Unity에서 실제 장면을 실행한 결과는 없다.

## 재검토 조건

아틀라스·스프라이트 뒤집기·애니메이션·렌더 파이프라인이 바뀌면 노멀 변환과 패스 비용을 재검증한다.

## 출처

- [Unity 6000.6 Secondary Textures](https://docs.unity.com/en-us/engine/6000.6/manual/unity2d/2d-urp/2d-index/secondary-textures): 노멀·마스크의 역할, UV 정렬, 가져오기 설정, 재질·광원 조건과 추가 패스 비용을 확인했다.
