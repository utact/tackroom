# MarkovJunior와 그래프 문법

확인: 2026-10-04.

## 요약

MarkovJunior는 격자 패턴 치환과 제약 전파를 결합하는 생성 언어다. 순서가 있는 규칙의 선택, 규칙의 합성, 미래 상태 조건을 모델로 표현한다. 그래프 문법은 연결 구조를 치환하는 원리이며 이 언어의 일부 모델로 구현된다.

## 문제 신호

생성 단계가 여러 번 바뀌거나, 경로·열쇠·잠금 관계를 결과 이미지보다 앞서 설계하려는 경우다.

## 기준선의 한계

좌표 조건과 반복문을 한 함수에 쌓으면 중간 상태와 규칙의 우선순위가 숨겨진다. 기준선은 명시적인 단계별 생성 함수와 작은 그래프이다.

## 원리

기본 모델은 격자에 맞는 첫 번째 치환 규칙을 찾고 그 규칙의 일치 위치 하나를 무작위로 선택한다. 중첩 노드로 순차 실행과 규칙 재탐색을 조합한다. 추론은 목표 상태에 대한 제약을 전파하며, 전파 성공만으로 목표에 실제 도달할 수 있다고 확정하지 않는다. 그래프 문법에서는 정점·간선의 치환과 보존 조건을 먼저 정의한다.

## 가치

규칙의 의미와 중간 상태를 읽을 수 있어 생성기를 수정하고 비교하기 쉽다. 동일 출력 종류 안에서도 미로, 연결 수정, 장식 단계를 나누어 학습할 수 있다.

## 트레이드오프와 리스크

규칙 순서가 결과와 종료에 영향을 준다. 치환의 순환, 목표 탐색의 비용, 디버깅용 임시 색의 최종 잔류를 관리해야 한다. 격자 구현을 임의 그래프용 범용 도구로 간주하면 모델 변환 비용을 놓친다.

## 대안과 경계

[WFC·ConvChain](pattern-synthesis.md)은 국소 패턴의 제약·분포를 다룬다. [L-system](../generation/branching.md)은 병렬 치환과 기하 해석에 초점을 둔다. MarkovJunior의 이름을 일반 확률 마르코프 연쇄와 동일시하지 않는다.

## 깊이 있는 활용

주 경로에 열쇠와 잠금을 삽입하는 BasicKeys 모델에서 진행 관계를 관찰할 수 있다. 이를 다른 도메인에 옮길 때는 열쇠 소유를 포함한 상태 공간으로 도달 가능성을 검사한다. 구조 치환과 그림 생성 사이에 검증 단계를 둔다.

## 임시방책의 신호

예제의 색을 바꾼 것만으로 새 생성 원리를 구현했다고 판단하거나, 규칙을 추가할 때마다 종료가 우연에 의존하는 경우다.

## 실패 재현

제안 실험: 한 상태를 만들고 다시 원래 상태로 돌리는 규칙 쌍을 둔다. 일치 규칙이 계속 존재하면 종료하지 않을 수 있다. 열쇠와 잠금 위치를 바꾼 변형에서는 단순 좌표 탐색과 소유 상태를 포함한 탐색 결과를 비교한다.

## 측정과 검증

규칙 적용 횟수·종료 이유·제약 실패 단계·목표 도달률을 기록한다. 시드와 규칙 순서를 고정하고 중간 상태를 저장한다. 원문과 모델 소스를 읽었으며 인터프리터를 실행한 결과는 없다.

## 재검토 조건

격자 밖의 연결 구조가 필요하거나 탐색 비용이 커지면 직접 그래프 문법, 명시적인 생성 함수, 제약 해결기를 비교한다. 모델이나 인터프리터가 바뀌면 종료·도달 검사를 다시 수행한다.
