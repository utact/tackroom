# 그래프 동형과 정규 라벨

확인: 2026-10-04.

## 요약

정점 이름이 달라도 연결 구조가 같은지 비교한다. 정규 라벨은 허용한 이름 변경 아래 같은 구조를 공통 표현으로 옮긴다. 어떤 정점·간선 속성을 보존할지가 비교의 핵심이다.

## 문제 신호

생성한 방·경로·의존 그래프의 구조 중복을 제거하거나, 이름을 바꾼 입력이 같은 결과로 취급되어야 하는 경우다.

## 기준선의 한계

간선 목록의 문자열 비교는 이름과 입력 순서에 민감하다. 정점 수와 차수 분포만 비교하면 다른 구조를 같은 것으로 취급할 수 있다. 작은 순열 완전 탐색을 기준선으로 둔다.

## 원리

동형은 정점 사이의 일대일 대응이 인접 관계를 보존하는 것이다. 정규화는 정점 분할·정제와 탐색 등으로 대표 라벨을 선택한다. nauty·Traces는 동형 관련 자동동형군과 정규 라벨을 계산하는 구현이며 입력 종류와 옵션을 맞춰 사용해야 한다.

## 가치

출력 이미지가 달라도 연결 구조가 같은 생성물을 셀 수 있다. 캐시·회귀 비교에서 임의 이름의 영향을 줄이고 생성기의 구조 다양성을 측정한다.

## 트레이드오프와 리스크

대칭이 큰 그래프는 탐색 부담이 달라진다. 좌표·방향·열쇠 종류를 무시하면 사용 의미가 다른 그래프를 합칠 수 있다. 대표 표현은 구현·옵션이 바뀌면 달라질 수 있으므로 영구 식별에는 버전을 포함한다.

## 대안과 경계

단순 트리나 제한된 그래프는 전용 정규화가 더 간단할 수 있다. 일반 해시는 구조를 정규화하지 않으며 충돌 가능성도 남는다. [콘텐츠 주소](../systems/content-addressing.md)는 이미 정해진 바이트의 동일성을 다룬다.

## 깊이 있는 활용

정점 색으로 방 역할을 구분하고 정규 라벨을 생성물 통계에 사용할 수 있다. 허용 회전·반사를 이름 변경과 따로 정의하면 그림의 대칭과 그래프의 대칭을 혼동하지 않는다.

## 임시방책의 신호

정규 키가 같다는 이유만으로 원본 검사를 생략하거나, 방향·속성이 누락된 입력으로 중복 제거하는 경우다.

## 실패 재현

제안 실험: 6개 정점의 순환 그래프와 두 삼각형은 정점 수와 각 차수가 같지만 연결 구조는 다르다. 이름 순열을 여러 번 적용한 동일 그래프와 함께 비교한다. 속성 하나를 바꾸면 동일성 판단이 어떻게 달라지는지도 확인한다.

## 측정과 검증

작은 그래프에서 순열 완전 탐색을 기준으로 동형 결과를 검증한다. 정규 표현의 이름 변경 불변성, 속성 보존, 처리 시간과 대칭별 편차를 측정한다. nauty를 실행한 성능 자료는 없다.

## 재검토 조건

유향·가중·다중 간선이나 속성이 추가되면 지원 입력과 동형 정의를 다시 맞춘다. 영구 키의 구현 버전이 바뀌면 기존 데이터의 재계산·호환 전략을 정한다.
