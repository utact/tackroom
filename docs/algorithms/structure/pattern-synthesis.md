# WaveFunctionCollapse와 ConvChain

확인: 2026-10-04.

## 요약

예제의 작은 패턴으로 새 배치를 합성한다. WFC는 허용 패턴의 국소 제약을 전파하고, ConvChain은 패턴 가중치로 정의한 분포를 향해 상태를 갱신한다. 허용 여부와 빈도는 서로 다른 요구다.

## 문제 신호

타일의 연결면을 맞추거나, 손으로 만든 작은 무늬에서 더 큰 질감을 얻으려는 경우다.

## 기준선의 한계

타일을 독립적으로 뽑으면 경계가 맞지 않는다. 예제를 그대로 반복하면 연결은 쉽지만 반복이 눈에 띈다. 기준선은 수작업 타일 규칙과 주기적 반복이다.

## 원리

WFC는 위치별 허용 상태를 유지하고 불확실성이 작은 위치를 선택한 뒤 이웃의 불가능한 상태를 제거한다. 허용 상태가 사라지면 모순이다. ConvChain은 입력의 패턴 빈도로 가중치를 만들고, 주변 패턴의 에너지 변화에 따라 픽셀 변경을 수락한다. Metropolis 방식은 에너지가 늘어도 온도에 따른 확률로 이동한다.

## 가치

규칙과 예제 데이터를 구현에서 분리한다. WFC로 경계의 합법성을, ConvChain으로 빈도와 질감의 변화를 관찰할 수 있다.

## 트레이드오프와 리스크

WFC가 국소 조건을 만족해도 출입구 간 연결이나 열쇠 획득 가능성은 별개다. 모순 처리와 재시도에는 예산이 필요하다. ConvChain의 유한 실행은 목표 분포에 도달했다는 증거가 아니며 입력에 없는 패턴도 나타날 수 있다.

## 대안과 경계

정확한 전체 덮개는 [Algorithm X](exact-cover.md), 진행 구조는 [MarkovJunior와 그래프 치환](markov-junior.md), 단순 지형 변화는 [노이즈](../generation/noise.md)와 비교한다. 세 방식은 같은 보장을 제공하지 않는다.

## 깊이 있는 활용

전체 경로를 먼저 고정하고 주변 장식에 WFC를 적용할 수 있다. ConvChain 결과를 질감 후보로 삼은 뒤 규칙 위반을 별도 검사하는 구성도 가능하다. 검사와 수정이 원래 분포를 바꾼다는 점을 기록한다.

## 임시방책의 신호

모순이 난 입력을 숨기거나, 보기 좋은 시드만 골라 성공률을 설명하는 경우다. 국소 규칙에 전역 요구를 계속 추가하면서 원인을 추적할 수 없어지는 것도 신호다.

## 실패 재현

제안 실험: 분리된 고리만 허용하는 타일로 생성한 뒤 출입구 연결을 검사한다. 국소 제약의 성공과 이동 실패를 동시에 기록한다. ConvChain에서는 온도·반복 횟수별로 예제에 없는 패턴 비율을 센다.

## 측정과 검증

WFC의 성공률·재시도 수·시간 상위 분위수와 전역 조건 통과율을 측정한다. ConvChain은 여러 독립 실행의 패턴 빈도·자기상관·입력과의 차이를 비교한다. 동일 경계 조건과 패턴 크기를 사용한다. 이 측정은 제안이며 프로젝트 실행 결과는 없다.

## 재검토 조건

입력 패턴 수가 늘거나 경계·연결 조건이 달라지면 메모리와 모순율을 재측정한다. 전역 조건 실패가 반복되면 구조를 먼저 구성하는 방식을 비교한다.
