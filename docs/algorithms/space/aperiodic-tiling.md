# 비주기 타일링과 hat 타일

확인: 2026-10-04.

## 요약

허용된 타일과 배치 규칙이 평면을 채우면서 주기적 평행이동을 허용하지 않는 구조다. 유한 자산의 반복 사용과 전체 배치의 비주기성을 구분한다.

## 문제 신호

반복 자산을 사용하면서 규칙적인 큰 주기를 피하는 배치나, 국소 규칙과 전체 구조의 관계를 탐색하려는 상황이다.

## 기준선의 한계

작은 반복 타일은 눈에 띄는 주기를 만든다. 무작위 타일 배치는 비주기성의 증명이나 올바른 평면 타일링을 제공하지 않는다.

## 원리

aperiodic tile set은 타일링은 가능하지만 주기적 타일링을 허용하지 않는 집합이다. hat 단일 도형의 타일링은 반사된 타일과 반사되지 않은 타일을 함께 사용한다. 논문은 메타타일·치환 구조를 이용해 전체 타일링을 분석한다.

## 가치

자산 종류 수와 배치 규칙의 복잡도를 분리한다. 작은 유한 패치를 만들어 치환 계층과 국소 모양의 재등장을 관찰한다.

## 트레이드오프와 리스크

전체 비주기성은 유한 패치에 같은 부분 모양이 없다는 뜻이 아니다. 회전·반사·좌표 오차·경계 처리가 필요하며 논문의 무한 평면 결과를 유한 화면의 미관 보장으로 옮기지 않는다.

## 대안과 경계

주기 타일은 단순한 편집·저장의 대안이다. [패턴 제약 생성](../structure/pattern-synthesis.md)은 다른 인접 규칙을 다루며 비주기 타일링과 동일한 보장이 아니다.

## 깊이 있는 활용

치환 단계의 경계를 유지해 패치를 확장하고 필요한 창만 출력한다. 자산의 방향별 변형과 구조 데이터는 따로 저장해 화풍을 교체할 수 있게 한다.

## 임시방책의 신호

반사를 금지한 자산으로 hat의 같은 결과를 기대하거나, 유한 그림을 보고 비주기성을 증명했다고 쓴다. 무작위 배열에 비주기 타일링이라는 이름을 붙인다.

## 실패 재현

반사 허용·금지를 바꾸어 구성 가능성을 비교한다. 패치 확장 경계의 틈·겹침과 좌표 반올림에 따른 모양 불일치를 검사한다.

## 측정과 검증

면적 피복·겹침·경계 일치, 치환 단계별 자산 수·출력 비용, 방향별 빈도를 기록한다. 유한 검사 결과와 논문의 무한 범위 증명을 구분한다.

## 재검토 조건

회전·반사 제한이나 유한 영역의 맞춤 편집이 필요하면 타일 집합·경계 알고리즘을 다시 검토한다.

## 출처
